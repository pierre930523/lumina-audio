# Lumina Audio App (Flutter + Impeller)

Phase 2 將透過 `flutter create` 初始化完整多平台專案（Windows / macOS / iOS / Android），並啟用 `shaders/` 中的 Impeller GLSL Fragment Shaders 與 `flutter_rust_bridge` 綁定。

## Shaders
- `shaders/mesh_fluid_bg.frag`：專輯封面 4 色動態流體背景
- `shaders/liquid_glass.frag`：Apple Music 風格液態玻璃邊緣折射與 1px 高光邊框
