# P08 全螢幕沉浸式播放 (Fullscreen Now Playing) 交互規格書

## 1. 頁面概述 (Page Overview)

- **功能定位**：Lumina Audio 的旗艦級全螢幕沉浸視聽視圖。打破傳統播放器的表格清單束縛，以即時運算的「封面動態流體網格著色器（Fluid Mesh Shader）」作為全螢幕動態背景，呈現巨幅發燒專輯封面、等寬排版、大字體逐字對齊動態歌詞（Word-by-word Synchronized Lyrics with Depth Blur）與大波形進度條。
- **所屬模組**：播放控制模組 (Playback Control / Fullscreen Immersion)
- **上游頁面**：底部播放器右側「全螢幕/歌詞按鈕」、封面縮圖點擊、全域快捷鍵 `Cmd/Ctrl+F` 或 `Cmd/Ctrl+L`
- **下游頁面**：按下 `Esc` 或點擊退出鍵無損還原至 P00 主工作區（原位置零遺失）、切換至 P07 懸浮膠囊
- **使用者目標**：在夜間、客廳或專注聽音場景下，獲得最高水準的視覺藝術享受與發燒音質深度沉浸。

## 4. 交互行為詳述 (Interaction Behaviors)

### C803 逐字同步動態歌詞 (Word-by-word Lyrics Interaction)
- **單擊跳轉 (Tap to Seek)**：
  - 使用者單擊任意歷史或未來的歌詞行，播放器立即尋道（Seek）至該歌詞起始時間戳，音訊平滑接續播放，該行瞬間躍升為焦點行。
- **手動滾動與自動回正 (Manual Scroll & Auto-snap)**：
  - 使用者透過滾輪上下翻閱歌詞時，系統暫停自動滾動鎖定，右下角浮現「回到底部最新」快捷藥丸。
  - 若使用者 5 秒內無任何滑動操作，歌詞視圖以彈簧曲線（Spring Curve）平滑回正至當前播放行。

### C806 滑鼠閒置自動隱藏 (Idle Auto-hide)
- **閒置隱藏**：滑鼠停留在畫面超過 3000ms，系統游標自動設置為隱藏（`SystemMouseCursors.none`），頂部工具條與底層控制欄以 400ms 平滑淡出（`opacity: 0.0`），進入純粹「視覺海報模式」。
- **即時喚醒**：滑鼠移動哪怕 1 像素，所有控制項立即以 120ms 淡入，游標同步還原。

### 鍵盤沉浸控制 (Keyboard)
- `Space`：播放/暫停；`Left/Right`：快退/快進 5 秒；`Up/Down`：音量調節；`Esc`：一鍵無失真退出全螢幕。

## 6. 動效說明 (Motion Specs)

### GLSL 封面流體著色器 (Fluid Mesh Shader)
- 提取封面調色盤中的 4 種主要色彩作為 Uniforms 傳入著色器。
- 以 60fps（支援高刷 120fps）計算 Perlin 噪聲流動，流動速率受音樂節奏感應微幅波動。

### 歌詞景深動效 (Depth Blur Animation)
- 當前行：`blur: 0px`, `scale: 1.05`, `color: #FFFFFF`（字體加粗，逐字向右推進高光）。
- 鄰近行（前/後 1 行）：`blur: 1.5px`, `scale: 1.0`, `color: rgba(255,255,255,0.6)`。
- 遠端行（前/後 2 行以上）：`blur: 3.5px`, `scale: 0.95`, `color: rgba(255,255,255,0.25)`。

## 7. 數據策略 (Data Loading Strategy)

- **毫秒級動態歌詞同步引擎 (Sub-frame Lyrics Sync)**：
  - 音訊時鐘透過 `AudioService.positionStream` 以 16ms 週期廣播當前微秒級位置。
  - 歌詞渲染器採用二分查找定位當前詞素，保證文字高光推進與歌聲發音零延遲同步。

## 8. 適配說明 (Adaptation Rules)

### 超寬螢幕與客廳電視適配
- **超寬螢幕 (21:9 或 32:9)**：
  - 封面與歌詞自動向中央收攏，兩側保持適當留白與著色器光暈，防止視線過於分散。
- **暗室保護 (Ambient Light Adaptation)**：
  - 背景亮度自適應降低 20%，防止夜間暗室環境中刺眼。

## 10. 特定場景微交互說明 (Micro-interaction Specifications)

**微交互場景：逐字發光推進 (Word-by-word Glowing Progression)**
1. **觸發條件**：音軌播放到達當前詞素時間戳。
2. **視覺變化**：
   - 該詞文字從淡灰色（`rgba(255,255,255,0.4)`）平滑轉為純白色（`#FFFFFF`）。
   - 字體外圍伴隨一道微弱的琥珀金色高光描邊（Shimmer 掃光，寬度 12px，隨發音時間等速向右推進）。
3. **動效參數**：精確吻合音軌 LRC 詞素持續時間（如 320ms），線性插值 `Curves.linear`。
4. **反饋**：視覺焦點高度跟隨歌聲節奏。
5. **程式碼偽代碼**：
```dart
ShaderMask(
  shaderCallback: (bounds) {
    return LinearGradient(
      colors: [Colors.white, LuminaTokens.accentAmber, Colors.white38],
      stops: [progress, progress + 0.05, progress + 0.1],
    ).createShader(bounds);
  },
  child: Text(word, style: activeLyricTextStyle),
)
```
