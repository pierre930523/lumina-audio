# P01 首頁儀表板 (Home Dashboard) 交互規格書

## 1. 頁面概述 (Page Overview)

- **功能定位**：Lumina Audio 的第一入口與資訊聚合中樞，彙整使用者最近播放、高頻聆聽專輯、依聽歌習慣推薦之發燒作品、新加入音樂庫之音軌及快速恢復播放入口。
- **所屬模組**：聚合推薦模組 (Browse / Home Hub)
- **上游頁面**：應用程式冷啟動（P23）、側邊欄「主頁」項目點擊、頂部全域歷史前進/後退鍵
- **下游頁面**：P03 專輯詳情頁（點擊推薦/歷史專輯卡片）、P05 藝人詳情頁（點擊推薦藝人頭像）、P08 全螢幕播放（點擊 Hero 推薦播放鍵）、P06 音區管理（點擊頂部狀態）
- **使用者目標**：在開啟播放器 3 秒內快速掌握曲庫動態，一鍵無縫繼續上次未聽完的高解析音樂。

## 4. 交互行為詳述 (Interaction Behaviors)

### C101 快速恢復播放卡片
- **單擊 (Tap)**：點擊卡片非播放按鈕區域，觸發 `navController.push(albumId)` 平滑進入 P03 專輯詳情頁。
- **懸浮 (Hover)**：卡片向上微浮 `2px`，液態玻璃背板邊框自 `var(--color-border-subtle)` 平滑過渡至 `var(--color-border-glow)`，游標變為 `pointer`。
- **鍵盤 (Keyboard)**：支援 `Tab` 鍵將焦點移至卡片，顯示 `2px` 琥珀色焦點外框（`:focus-visible`），按 `Enter` 觸發導航，按 `Space` 觸發播放。

### C104 專輯展示卡片
- **單擊 (Tap)**：直接進入對應專輯詳情 P03。
- **懸浮 (Hover)**：封面微縮放（`1.0` → `1.03`，時間 200ms），右下角平滑浮出圓形半透明播放按鈕 C105。
- **右鍵選單 (Context Menu)**：彈出 P26 曲目/專輯選單（項目：播放、下一首播放、加入佇列、複製連結、標記收藏）。

## 5. 頁面狀態流轉 (State Machine)

| 狀態 | 觸發條件 | 視覺表現 | 可執行操作 |
|------|---------|---------|-----------|
| **預設態 (Default)** | 首頁曲庫中繼資料與歷史載入完成 | 正常展示 Hero、輪播軌與網格 | 所有點擊、播放、導覽操作 |
| **加載態 (Loading)** | 首次開啟或全域中繼資料快取重建中 | 展示骨架屏（Hero 圓角方塊 + 網格骨架脈衝微光） | 可點擊側欄切換至其他已快取頁面 |
| **空態 (Empty)** | 本地尚未掛載任何音樂目錄且未綁定串流服務 | 簡約向量線稿插圖 + 引導文案「曲庫尚無音樂」 + 「新增音樂目錄」CTA 按鈕 | 單擊 CTA 開啟 P15 目錄掛載嚮導 |
| **錯誤態 (Error)** | 本地資料庫讀取異常或核心服務中斷 | 錯誤插圖 + 錯誤代碼說明 + 「重新整理」按鈕 | 單擊重試重新拉取首頁快取 |
| **無權限態 (No Access)** | 訪問遠端共用資料夾被拒絕 | 提示「無法連線至遠端儲存庫」+「檢查憑證」按鈕 | 點擊跳轉至 P14 網路設定 |
| **部分加載態 (Partial)** | 本地曲庫成功，但串流服務（Qobuz/Tidal）離線 | 頂部微型橫幅提示「串流服務暫時離線」，本地推薦正常展示 | 可點擊橫幅重試串流連線 |
| **編輯態 (Edit)** | 使用者點擊「自訂首頁佈局」 | 區塊出現拖曳把手與可隱藏核取方塊 | 拖曳調整分區上下順序、隱藏特定模組 |

## 6. 動效說明 (Motion Specs)

### 頁面轉場 (Page Transitions)
- **進入方式**：透過側邊欄或歷史導覽進入時，採用 `FadeThrough`（透明度淡入 + 輕微上移 8px），時長 `var(--motion-duration-page)` (200ms)，曲線 `var(--motion-easing-standard)`。
- **退出方式**：進入二級詳情頁時，主視圖維持原位並淡出，新頁面滑入。

### 元素動畫 (Element Animations)
- **卡片懸浮**：`transform: translateY(-2px) scale(1.02)`，時長 180ms，曲線 `Curves.easeOutCubic`。
- **骨架屏脈衝**：透明度在 0.3 至 0.7 間循環平滑過渡，週期 1200ms。

## 7. 數據策略 (Data Loading Strategy)

- **首次加載**：優先自本地 SQLite/WAL 高速快取讀取首頁索引資料（<50ms 即可渲染第一幀）。
- **非同步更新**：背景靜默比對串流服務新動態，若有新推薦則以無感漸變更新內容。
- **快取機制**：首頁結構快取至記憶體中，切換側欄分頁時保留檢視狀態與滾動偏移量。

## 8. 適配說明 (Adaptation Rules)

### PC 桌面端視窗自適應
- **視窗最小尺寸**：880 × 580 px。
- **分欄佈局響應**：
  | 視窗寬度 | 側邊欄狀態 | 主內容網格列數 | Hero 卡片佈局 |
  |---------|-----------|--------------|--------------|
  | < 960px | 自動折疊為 56px 圖標模式 | 3 列 | 緊湊模式 (封面置頂，文字置底) |
  | 960–1280px | 展開 220px | 4–5 列 | 左右分欄 (左封面，右中繼與操作) |
  | ≥ 1280px | 展開 220px | 6–8 列 | 大寬幅沉浸分欄 |
- **深色模式**：遵循曜石暗黑 `var(--color-bg-canvas)`，卡片底色為 `var(--color-surface-card)`，邊框為 `var(--color-border-subtle)`。
- **無障礙**：所有專輯卡片朗讀格式為：「專輯名稱，藝術家名稱，音訊格式，按 Enter 檢視詳情」。

## 10. 特定場景微交互說明 (Micro-interaction Specifications)

**微交互場景：Hero 一鍵恢復播放按鈕 (Hero Resume Play Button)**
1. **觸發條件**：滑鼠點擊 C102 播放按鈕，或鍵盤聚焦後按 Space 鍵。
2. **視覺變化**：
   - 按鈕圖示由 `Icons.play_arrow_rounded` 平滑形態變換為 `Icons.pause_rounded`（使用 AnimatedIcon）。
   - 按鈕背景由發燒琥珀色高光擴散出一圈輕微的波紋光暈（擴散半徑 8px，透明度由 0.4 降至 0）。
3. **動效參數**：時長 200ms，曲線 `Curves.easeOutQuad`。
4. **聲音/觸覺反饋**：桌面端無系統震動，播放器底欄進度條立即啟動前進。
5. **狀態反轉**：再次點擊暫停，圖示變換回播放，波紋收縮，音訊執行 150ms 交叉淡化防爆音淡出。
6. **程式碼偽代碼**：
```dart
AnimatedCrossFade(
  firstChild: Icon(Icons.play_arrow_rounded, color: Colors.black),
  secondChild: Icon(Icons.pause_rounded, color: Colors.black),
  crossFadeState: isPlaying ? CrossFadeState.showSecond : CrossFadeState.showFirst,
  duration: const Duration(milliseconds: 200),
)
```
