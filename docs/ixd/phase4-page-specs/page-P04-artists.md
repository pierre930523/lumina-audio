# P04 藝術家曲庫 (Artists Library) 交互規格書

## 1. 頁面概述 (Page Overview)

- **功能定位**：呈現音樂庫中所有藝術家（創作者、演奏家、指揮家、樂團）的視覺化名錄。採用高清晰圓形頭像（Circular Avatar）網格排布，並支援字母索引、發行專輯總數統計、音樂流派篩選與熱度排序。
- **所屬模組**：典藏曲庫模組 (Library / Artists)
- **上游頁面**：側邊欄「藝術家」標籤、頂部全域歷史前進/後退鍵、P01 首頁藝人推薦
- **下游頁面**：P05 藝術家詳情頁（點擊任意藝人頭像/卡片）、全域搜尋（P12）
- **使用者目標**：快速縱覽曲庫中所有藝人陣容，透過經典圓形頭像辨識並進入深層音樂作品檔案。

## 4. 交互行為詳述 (Interaction Behaviors)

### C401 藝術家卡片
- **單擊 (Tap)**：觸發 `navController.push(artistName)`，進入 P05 藝人詳情頁。
- **懸浮 (Hover)**：
  - 圓形頭像微幅放大（`scale: 1.04`，200ms）。
  - 頭像中央淡入半透明深色遮罩（`rgba(0,0,0,0.4)`），並居中浮現 C402 播放按鈕。
  - 藝人名稱文字轉為高亮白色，專輯數文字轉為發燒金色。
- **右鍵選單 (Context Menu)**：
  - 彈出選單：播放熱門曲目、加入播放佇列、開啟藝人關係圖譜（Credits Graph）、編輯藝人頭像。
- **鍵盤控制 (Keyboard)**：
  - 支援全域鍵盤方向鍵自由遊走，焦點外框緊貼圓形頭像呈圓形高光光環（`box-shadow: 0 0 0 2px var(--color-accent-amber)`）。

## 5. 頁面狀態流轉 (State Machine)

| 狀態 | 觸發條件 | 視覺表現 | 可執行操作 |
|------|---------|---------|-----------|
| **預設態 (Default)** | 藝人索引資料載入完成 | 整齊圓形網格，頭像清晰 | 所有點擊、播放、篩選操作 |
| **加載態 (Loading)** | 首次讀取中繼快取 | 圓形脈衝骨架圈 + 文字骨架線條 | 頂部全域後退可用 |
| **空態 (Empty)** | 篩選條件無匹配藝人或曲庫無藝人資料 | 空態向量圖 +「無對應藝術家」+「重設過濾」按鈕 | 單擊重設按鈕還原 |
| **錯誤態 (Error)** | 藝人關係資料庫讀取異常 | 錯誤提示 +「修復曲庫索引」按鈕 | 單擊重試 |
| **部分加載態 (Partial)** | 部分藝人無專屬線上藝人寫真 | 使用該藝人代表專輯封面作為頭像底圖，外圈以高斯模糊修飾 | 背景自動排程拉取 MusicBrainz 頭像 |

## 6. 動效說明 (Motion Specs)

### 轉場與懸浮動效
- **頁面轉場**：`FadeThrough`（時長 200ms），頭像網格以輕微交錯式自底向上淡入（`duration: 250ms`, `stagger: 10ms`）。
- **頭像懸浮光環**：懸浮時圓形外框由無到有展開一圈 2px 半透明金色光暈，時長 180ms，曲線 `Curves.easeOutCubic`。

---

## 7. 數據策略 (Data Loading Strategy)

- **高效分頁與虛擬網格**：使用 `SliverGrid` 協同虛擬化架構，不論曲庫擁有 100 位還是 10,000 位藝術家，記憶體開銷恆定保持在 50MB 以內。
- **獨立藝人頭像快取機制**：
  - 藝人頭像獨立於專輯封面快取，優先自本地藝人寫真目錄加載；若無則非同步請求 Discogs / MusicBrainz；兜底方案則取其最佳專輯封面中央裁切為圓形。

---

## 8. 適配說明 (Adaptation Rules)

### 視窗響應演算法
- 圓形頭像卡片直徑自適應：保持在 120px 至 160px 之間：
  - 寬度 < 960px：4 列網格（折疊側欄）
  - 寬度 960–1280px：5–6 列網格
  - 寬度 > 1280px：7–9 列網格
- **無障礙支援**：螢幕朗讀器自動播報「藝術家：張三，收錄 15 張專輯，按 Enter 進入作品列表」。

## 10. 特定場景微交互說明 (Micro-interaction Specifications)

**微交互場景：頭像居中快捷播放鈕 (Center Avatar Play Overlay)**
1. **觸發條件**：滑鼠懸浮於藝人圓形頭像 C401 表面。
2. **視覺變化**：
   - 頭像表面覆蓋一層圓形半透明遮罩（`rgba(0,0,0,0.4)`）。
   - 中央浮現白色播放圖示，圖示外圍環繞半透明晶質毛玻璃邊框。
   - 點擊時播放圖示執行 `scale(0.88)` 按壓反彈動畫，底欄播放器立即載入該藝人最熱門曲目開始播放。
3. **動效參數**：淡入時長 160ms，按壓回彈時長 140ms，曲線 `Curves.easeOutQuad`。
4. **程式碼偽代碼**：
```dart
ClipOval(
  child: Stack(
    children: [
      AvatarImage(...),
      if (isHovered)
        Container(
          color: Colors.black38,
          alignment: Alignment.center,
          child: GlassPlayCircle(),
        ),
    ],
  ),
)
```
