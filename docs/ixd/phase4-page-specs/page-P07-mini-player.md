# P07 懸浮液態迷你播放器 (Mini-Player) 交互規格書

## 1. 頁面概述 (Page Overview)

- **功能定位**：Lumina Audio 的獨立輕量桌面伴侶視圖。使用者可將主視窗縮小或切換為精巧的「液態玻璃懸浮膠囊（Floating Liquid Capsule）」，停靠於螢幕任意角落或設定常駐置頂（Always on Top），在進行寫作、程式碼開發或日常工作時，以極小空間佔用掌控播放。
- **所屬模組**：播放控制模組 (Playback Control / Mini-Player)
- **上游頁面**：底部播放器右側「膠囊切換鈕」、全域快捷鍵 `Cmd/Ctrl+M`、主視窗點擊縮小至膠囊
- **下游頁面**：P00 桌面端主工作區（點擊膠囊展開按鈕或雙擊膠囊主體）、P08 全螢幕播放（點擊全螢幕鈕）
- **使用者目標**：在不打擾核心工作的前提下，以高階美感持續享受音樂，並快速完成暫停、切歌、音量微調與音軌資訊預覽。

## 4. 交互行為詳述 (Interaction Behaviors)

### C701 膠囊拖曳與螢幕磁吸 (Drag & Magnetic Snap)
- **拖曳移動**：
  - 滑鼠左鍵在膠囊任意非按鈕區域按下並移動，視窗以 1:1 跟手率跟隨游標移動。
  - 當膠囊邊界靠近桌面螢幕邊緣（距離 < 24px）時，視窗自動產生微阻尼感並**磁吸**至邊界，自動吸附整齊。
- **雙擊還原 (Double Click)**：
  - 雙擊膠囊主體，視窗平滑執行 `Scale + Expand` 動畫，瞬間還原為全尺寸 P00 主視窗。

### C706 系統級視窗置頂 (Pin to Top)
- **單擊啟用**：
  - 釘子圖示平滑旋轉 45 度，光澤轉為金色，視窗呼叫原生 Desktop API 設定為全系統最上層顯示（即便使用者切換至瀏覽器或 IDE，膠囊亦不被遮擋）。

### C704 膠囊進度條懸浮展開
- **懸浮放大**：
  - 滑鼠游標移入進度條區域，進度條高度由 `2px` 平滑展開至 `6px`，進度球（Thumb）彈性放大出現，支援滑鼠任意點擊尋道。

## 5. 頁面狀態流轉 (State Machine)

| 狀態 | 觸發條件 | 視覺表現 | 可執行操作 |
|------|---------|---------|-----------|
| **預設常規態 (Default)** | 音訊正在播放中 | 膠囊背景隨封面色調微光流動，進度條勻速前進 | 暫停、切歌、拖曳、置頂 |
| **懸浮擴展態 (Hover)** | 滑鼠移入膠囊表面 | 音量滑桿與進度條等微調組件平滑浮現，操作按鈕高亮 | 精細音量調節、尋道操作 |
| **暫停休眠態 (Paused)** | 使用者點擊暫停 | 封面流體動畫平緩停止，背景透明度提升，節省 GPU 算力 | 點擊播放按鈕隨時喚醒 |
| **音訊緩衝態 (Buffering)** | 串流網路波動正在重新載入緩衝 | 封面外圈呈現環形進度環旋轉，曲名暫時變灰 | 可切換下一首本地曲目 |
| **斷網/空閒態 (Idle)** | 播放清單結束或曲庫未載入 | 膠囊展示預設 Lumina 標誌 + 文案「無播放中曲目」 | 點擊展開主視窗選歌 |

## 6. 動效說明 (Motion Specs)

### 膠囊型態切換動畫
- **自主視窗收縮為膠囊**：
  - 主視窗以 `Curves.fastOutSlowIn` 向右下角快速平滑收縮，邊角圓角逐漸增大至 42px，耗時 260ms。
- **還原主視窗**：
  - 膠囊自當前位置瞬間向外彈性舒展為原始視窗尺寸，耗時 240ms。

## 7. 數據策略 (Data Loading Strategy)

- **主程序與膠囊雙向 IPC 通訊 (High-speed IPC)**：
  - 迷你播放器可作為主程序之獨立輕量視窗（Multi-window）或懸浮 Overlay。
  - 播放進度（毫秒級）、歌詞當前行與音訊狀態透過記憶體共用緩衝區零延遲同步。

## 8. 適配說明 (Adaptation Rules)

### 多螢幕跨螢幕自適應
- **多顯示器支援**：膠囊可自由拖曳跨越主螢幕與副螢幕，自動記憶使用者最後放置的螢幕編號與相對座標百分比。
- **DPI 縮放自適應**：在 4K 螢幕（200% DPI）與標準 1080p 螢幕之間跨越時，膠囊字體與按鈕無失真自適應等比例縮放。

## 10. 特定場景微交互說明 (Micro-interaction Specifications)

**微交互場景：螢幕邊緣磁吸回彈 (Screen Edge Magnetic Snapping)**
1. **觸發條件**：拖曳膠囊放開滑鼠時，膠囊邊界距離螢幕四周小於 24px。
2. **視覺變化**：
   - 膠囊不再停留在半空中，而是被平滑「吸附」至距離邊界 12px 處。
   - 吸附瞬間膠囊產生極輕微的擠壓回彈（X 或 Y 軸 `scale(0.98)` 後以彈性曲線復原至 `1.0`）。
3. **動效參數**：位移時長 160ms，曲線 `Curves.easeOutBack`。
4. **反饋**：膠囊貼邊時邊框短暫閃爍一道微光（Shimmer 100ms）。
5. **程式碼偽代碼**：
```dart
void onPanEnd(DragEndDetails details) {
  final snapPos = calculateNearestScreenCorner(currentPos, threshold: 24.0);
  animateToPosition(snapPos, curve: Curves.easeOutBack, duration: const Duration(milliseconds: 160));
}
```
