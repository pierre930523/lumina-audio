# P05 藝術家詳情頁 (Artist Detail) 交互規格書

## 1. 頁面概述 (Page Overview)

- **功能定位**：呈現單一藝術家的全方位音樂世界，包含獨立高解析藝人寫真頭像（Independent Artist Avatar）、代表熱門曲目試聽、依分類排列之歷年作品（錄音室專輯 / 現場錄音 / EP與單曲 / 參與客串）、合作樂手圖譜與生平簡介。
- **所屬模組**：典藏曲庫模組 (Library / Artist Detail)
- **上游頁面**：P04 藝術家列表卡片點擊、P03 專輯詳情頁藝人連結點擊、P01 首頁推薦藝人、全域搜尋（P12）
- **下游頁面**：P03 專輯詳情頁（點擊歷年作品之專輯卡片）、P08 全螢幕播放、P27 播放佇列側欄
- **核心設計革新 (Key Interaction Innovations)**：
  1. **全域單一導覽錨點 (Single Navigation Anchor)**：堅決剔除舊版在藝人頭像旁注入的 `showInlineBackButton` 次級返回條。全域導覽完全依託頂部工具列之 `<` `>` 按鈕，無論深層經歷「專輯 A → 藝人 → 專輯 B → 合作藝人」，回退路徑皆精準可預期。
  2. **獨立藝人頭像 (Independent Avatar Entity)**：徹底將藝人頭像從導覽功能中解耦，頭像回歸純粹的藝術本體。具備獨立懸浮高光、母帶級寫真展示與一鍵播放藝人精選功能。
  3. **動態吸頂平滑銜接 (Sticky Header Transition)**：當內容向上滾動超過 180px 時，藝人姓名與播放快捷鈕優雅淡入頂部全域導覽列，視線不中斷。

## 4. 交互行為詳述 (Interaction Behaviors)

### A. 獨立頭像與單一導覽錨點解耦規範
- **解耦原則**：
  - 舊版介面中將返回箭頭嵌入頭像左上方，嚴重破壞頭像構圖美感，且引發與頂部歷史導覽 `<` 鍵的重複衝突。
  - 本規格書明確將 C501 獨立頭像定義為**純視覺與藝人精選實體**。
  - 返回操作 100% 依託頂部全域 `<` 鍵，點擊 `<` 即時回溯至進入前的上一頁（如 P03 專輯 A 或 P04 藝人庫），並透過 `PageStorageKey` 精準還原上一頁的滾動位置。
- **C501 獨立頭像互動**：
  - **懸浮 (Hover)**：頭像周圍以 200ms 浮現一圈 `2px` 琥珀色微光邊框，中央淡入半透明播放圖示。
  - **單擊 (Tap)**：直接播放該藝人最熱門第一首曲目。

### B. C506 歷年作品雙向跳轉互動
- **單擊 (Tap)**：點選某一專輯卡片，觸發 `navController.push(albumId)` 進入該專輯詳情 P03。
- **雙向探索回溯**：
  - 使用者在 P03 中再次點擊製作群中的客串歌手姓名，可推進至新藝人之 P05。
  - 全域頂部導覽列之 `<` 按鈕支援任意深度的逐層精準回退，歷史深度指示清晰。

### C. C504 熱門代表作清單互動
- **雙擊曲目行**：直接播放該首代表作。
- **右鍵選單**：支援「下一首播放」、「加入播放佇列」、「在該專輯中查看」。

## 5. 頁面狀態流轉 (State Machine)

| 狀態 | 觸發條件 | 視覺表現 | 可執行操作 |
|------|---------|---------|-----------|
| **預設態 (Default)** | 藝人中繼、代表作與歷年專輯完整載入 | 獨立頭像清晰、熱門曲目排布完整、作品網格分類清晰 | 所有播放、導覽與版本瀏覽操作 |
| **加載態 (Loading)** | 進入頁面且本地正在關聯檢索該藝人之所有曲目 | 頂部圓形骨架圈 + 熱門列表 6 條骨架條 + 網格占位塊 | 頂部全域後退鍵可用 |
| **空態 (Empty)** | 該藝人所有收錄音軌已被使用者自曲庫刪除 | 頭像黑白化 + 提示文案「曲庫中暫無該藝術家作品」+「返回曲庫」按鈕 | 單擊按鈕返回 P04 |
| **錯誤態 (Error)** | 關聯資料庫查詢失敗 | 錯誤圖示 +「重試查詢」按鈕 | 單擊重試 |
| **部分加載態 (Partial)** | 本地音軌齊全，但線上藝人寫真與生平載入超時 | 獨立頭像使用最佳專輯封面裁切替代，生平區域摺疊隱藏 | 音樂播放不受任何阻礙 |

## 6. 動效說明 (Motion Specs)

### 滾動吸頂動效
- **吸頂觸發**：當 `_scrollController.offset > 180.0` 時，頂部全域工具列中央的動態標題插槽啟動：
  - 透明度：`opacity = ((offset - 180) / 60).clamp(0.0, 1.0)`
  - 微縮頭像（32×32px 圓形）平滑浮現，右側緊貼藝人名稱與播放小圖示。
  - 滾動回滾小於 180px 時，吸頂內容於 120ms 內平滑淡出，乾淨俐落。

---

## 7. 數據策略 (Data Loading Strategy)

- **高效關聯聚合 (Relational Aggregation)**：
  - 藝人名錄與曲目關聯由 Rust 底層 SQLite `library_index_cache` 於背景執行預編譯查詢（Prepared Statement），耗時 < 15ms。
  - 歷年發行作品依發行年份（Release Year）自動倒序排列，現場錄音（Live）與 EP 自動分離為獨立群組。

---

## 8. 適配說明 (Adaptation Rules)

### 桌面端響應佈局
- **寬螢幕模式 (≥ 800px)**：Hero 區採用左側獨立圓形頭像（160px）+ 右側巨型姓名與按鈕並列排布。
- **窄螢幕模式 (< 800px)**：Hero 區自適應為居中堆疊排布，頭像微縮為 120px 居中。
- **無障礙支援**：獨立頭像提供語意標籤 `Semantics(label: '藝術家寫真頭像，按 Enter 播放精選作品')`。

## 10. 特定場景微交互說明 (Micro-interaction Specifications)

**微交互場景：關注藝人按鈕切換 (Follow / Unfollow Toggle)**
1. **觸發條件**：單擊 C503 關注按鈕。
2. **視覺變化**：
   - 未關注態：細線外框按鈕，文字「關注」，圖示 `Icons.favorite_border_rounded`。
   - 點擊瞬間：按鈕輕微縮小至 `scale(0.94)`，隨後彈回至 `1.0`。
   - 已關注態：背景轉為金色半透明漸變，文字變為「已關注」，圖示平滑過渡為金色實心愛心 `Icons.favorite_rounded`，同時向外釋放 4 顆微型金色粒子特效（粒子淡出時間 240ms）。
3. **動效參數**：時長 200ms，曲線 `Curves.easeOutBack`。
4. **反饋**：底欄狀態短暫提示：「已將該藝術家加入您的發燒關注名冊」。
5. **程式碼偽代碼**：
```dart
AnimatedCrossFade(
  firstChild: OutlinedButton.icon(icon: Icon(Icons.favorite_border), label: Text('關注')),
  secondChild: FilledButton.icon(icon: Icon(Icons.favorite, color: LuminaTokens.accentAmber), label: Text('已關注')),
  crossFadeState: isFollowed ? CrossFadeState.showSecond : CrossFadeState.showFirst,
  duration: const Duration(milliseconds: 200),
)
```
